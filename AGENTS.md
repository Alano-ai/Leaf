# Leaf

- Read [the architecture and milestones](docs/architecture.md) before expanding scope. Implement and verify one milestone at a time.
- Use Swift 6 and native SwiftUI controls. Reserve AppKit for system integrations that need it. Let macOS provide Liquid Glass in navigation and keep reading content legible.
- Keep reading local and conversion independent. Assess functionality, licensing, and performance before adding a dependency. Support unprotected books only.
- Preserve user files and configuration. Build and test the shared `Leaf` scheme on My Mac before committing. Push only when explicitly requested.
